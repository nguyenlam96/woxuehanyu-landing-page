1. Giọng đọc AI là gì?1. What is AI voice?

Khi bạn mở một bài đọc trong Wo xue Hanyu và bấm Giọng đọc AI, app sẽ gửi chữ trong bài cho một dịch vụ trí tuệ nhân tạo chuyên đọc văn bản (gọi là nhà cung cấp, ví dụ Soniox, ElevenLabs...). Dịch vụ đó "đọc" bài và trả về một file audio nghe như người thật.

Sau khi tạo xong, bạn có thể:

  • Nghe bài đọc với giọng tự nhiên, chọn tốc độ phù hợp.
  • Luyện Nghe chép chính tả và Shadowing (nói đuổi) theo audio vừa tạo.
  • Tải file audio về máy để nghe offline.
  • Tạo nhiều phiên bản với giọng khác nhau và chọn bản bạn thích.

When you open a reading in Wo xue Hanyu and tap AI voice, the app sends the text of that reading to an artificial-intelligence service that specialises in reading text aloud (we call it a provider, e.g. Soniox, ElevenLabs...). The service "reads" it and sends back an audio file that sounds like a real person.

Once it's made, you can:

  • Listen to the reading in a natural voice, at the speed you like.
  • Practise Dictation and Shadowing with the new audio.
  • Download the audio file to listen offline.
  • Make several versions with different voices and keep the one you like.

2. API Key là gì? Vì sao cần?2. What is an API key, and why do I need one?

Hãy tưởng tượng nhà cung cấp giọng đọc giống như một quán cà phê, còn API Key là thẻ thành viên của bạn ở quán đó.

  • Bạn đăng ký tài khoản ở trang của nhà cung cấp (giống làm thẻ thành viên).
  • Nhà cung cấp đưa cho bạn một dãy ký tự dài, ví dụ sk_a1b2c3d4e5.... Đó chính là API Key.
  • Bạn dán dãy đó vào app. Mỗi lần tạo giọng đọc, app "trình thẻ" này để nhà cung cấp biết ai đang dùng và tính phí vào đúng tài khoản của bạn.

Wo xue Hanyu không thu thập API Key của bạn: key chỉ được lưu trên thiết bị của bạn.

Think of a voice provider as a coffee shop, and an API key as your membership card there.

  • You sign up on the provider's website (like getting a membership card).
  • The provider gives you a long string of characters, e.g. sk_a1b2c3d4e5.... That is your API key.
  • You paste it into the app. Each time you make a voice, the app "shows the card" so the provider knows it's you and charges your own account.

Wo xue Hanyu does not collect your API key: it is stored only on your device.

4. Cách lấy API Key từng nhà cung cấp4. Getting a key from each provider

Trong app, khi bấm Nhập API Key sẽ có nút Lấy API Key mở thẳng tới đúng trang bên dưới. Giao diện của các trang có thể thay đổi theo thời gian, nhưng các bước chính thường giống nhau: đăng ký → (nạp tiền nếu cần) → tạo key → sao chép.

In the app, tapping Add API Key shows a Get an API Key button that opens the right page below. The websites may change their look over time, but the main steps stay the same: sign up → (add credit if needed) → create a key → copy it.

  1. Mở console.soniox.com và đăng ký bằng email hoặc tài khoản Google.
  2. Nếu tài khoản chưa có tiền dùng thử, vào mục Billing để thêm phương thức thanh toán hoặc nạp tiền.
  3. Vào mục API Keys, bấm Create API key (tạo key mới), đặt tên tùy ý, ví dụ "WoXueHanyu".
  4. Bấm sao chép key vừa hiện ra.
  5. Mở app, chọn nhà cung cấp Soniox → Nhập API Key → dán vào ô API key → lưu.
  1. Open console.soniox.com and sign up with email or a Google account.
  2. If the account has no trial credit, go to Billing to add a payment method or credit.
  3. Go to API Keys, tap Create API key, and give it any name, e.g. "WoXueHanyu".
  4. Copy the key that appears.
  5. In the app, pick Soniox → Add API Key → paste it into API key → save.

Alibaba CosyVoice

CosyVoice chạy trên nền tảng Model Studio (tiếng Trung: 百炼 / Bailian). Key ở đây gọi là DashScope API key. Có hai phiên bản, hãy chọn một:

CosyVoice runs on Alibaba's Model Studio (Chinese: 百炼 / Bailian). The key is called a DashScope API key. There are two editions, pick one:

  • Quốc tế (Singapore): đăng ký tại alibabacloud.com, sau đó mở Model Studio (quốc tế). Phù hợp với đa số người dùng ngoài Trung Quốc.
  • Trung Quốc (Beijing): đăng ký tại bailian.console.aliyun.com. Thường cần xác minh danh tính Trung Quốc.
  • International (Singapore): sign up at alibabacloud.com, then open Model Studio (international). Best for most people outside China.
  • China (Beijing): sign up at bailian.console.aliyun.com. Usually needs Chinese identity verification.
  1. Đăng nhập Model Studio, bấm kích hoạt dịch vụ nếu được hỏi (tài khoản mới thường có lượng dùng thử miễn phí).
  2. Vào mục API Key (thường ở góc trên bên phải hoặc menu bên trái), bấm Create API Key và sao chép key (bắt đầu bằng sk-).
  3. Mở app, chọn Alibaba CosyVoice → Nhập API Key → dán vào ô DashScope API key → ở ô Region chọn đúng phiên bản bạn đã đăng ký: International (Singapore) hoặc China (Beijing).
  1. Sign in to Model Studio and activate the service if asked (new accounts usually get a free trial quota).
  2. Open API Key (usually top-right or in the left menu), tap Create API Key and copy it (it starts with sk-).
  3. In the app, pick Alibaba CosyVoice → Add API Key → paste into DashScope API key → under Region choose the edition you signed up for: International (Singapore) or China (Beijing).

Key của bản quốc tế không dùng được cho bản Trung Quốc và ngược lại. Chọn sai Region sẽ báo key không hợp lệ.

An international key doesn't work in the China edition and vice versa. The wrong region makes the key look invalid.

Tài liệu:Docs: alibabacloud.com/help

Google Cloud

  1. Mở console.cloud.google.com và đăng nhập bằng tài khoản Google.
  2. Tạo một Project mới (ví dụ "WoXueHanyu TTS").
  3. Bật Billing (thanh toán) cho project: cần thêm thẻ.
  4. Tìm và bật Cloud Text-to-Speech API (bấm Enable).
  5. Vào APIs & Services → Credentials, bấm Create credentials → API key và sao chép key.
  6. Khuyên làm: bấm vào key vừa tạo → API restrictions → chỉ cho phép Cloud Text-to-Speech API để an toàn hơn.
  7. Mở app, chọn Google Cloud → Nhập API Key → dán → lưu.
  1. Open console.cloud.google.com and sign in with a Google account.
  2. Create a new Project (e.g. "WoXueHanyu TTS").
  3. Turn on Billing for the project: a card is required.
  4. Find and enable the Cloud Text-to-Speech API (tap Enable).
  5. Go to APIs & Services → Credentials, tap Create credentials → API key and copy it.
  6. Recommended: open the new key → API restrictions → allow only Cloud Text-to-Speech API, for safety.
  7. In the app, pick Google Cloud → Add API Key → paste → save.

iFlytek (讯飞)

iFlytek cần 3 thông tin thay vì một key.

iFlytek needs 3 values instead of one key.

  1. Mở console.xfyun.cn, đăng ký (注册) và đăng nhập (登录). Có thể cần xác minh danh tính (实名认证).
  2. Tạo ứng dụng mới: bấm 创建新应用 (tạo ứng dụng mới), điền tên bất kỳ.
  3. Mở ứng dụng vừa tạo, chọn dịch vụ 超拟人语音合成 (tổng hợp giọng siêu tự nhiên), nhận gói dùng thử miễn phí nếu có.
  4. Ở góc phải trang dịch vụ có mục 服务接口认证信息 với 3 dòng: APPID, APISecret, APIKey.
  5. Mở app, chọn iFlytek → Nhập API Key → sao chép và dán đúng từng dòng vào ô tương ứng (cẩn thận đừng đảo APIKey và APISecret).
  1. Open console.xfyun.cn, sign up (注册) and sign in (登录). Identity verification (实名认证) may be required.
  2. Create a new app: tap 创建新应用 (create new app) and give it any name.
  3. Open that app and pick the 超拟人语音合成 (super-natural speech synthesis) service; claim the free trial package if offered.
  4. On the right side of the service page, the 服务接口认证信息 box shows 3 lines: APPID, APISecret, APIKey.
  5. In the app, pick iFlytek → Add API Key → copy and paste each line into its matching field (don't swap APIKey and APISecret).

5. Nhập API Key vào app5. Adding the key in the app

  1. Mở một bài đọc bất kỳ, bấm Giọng đọc AI.
  2. Ở mục nhà cung cấp, chọn nhà cung cấp bạn vừa lấy key.
  3. Bấm Nhập API Key, dán key (và chọn Region nếu có), rồi bấm lưu. App sẽ kiểm tra key giúp bạn.
  4. Chọn giọng đọc: bấm nút nghe thử ▶ để nghe mẫu trước khi chọn. Điều chỉnh tốc độ nếu muốn.
  5. Xem ô ước tính (thời lượng, số ký tự), rồi bấm Tạo giọng đọc AI.
  6. Đợi vài giây tới vài phút tùy độ dài bài. Xong rồi, bạn có thể nghe, luyện chép chính tả, shadowing hoặc tải file về.
  1. Open any reading and tap AI voice.
  2. In the provider section, pick the provider you got the key from.
  3. Tap Add API Key, paste the key (and pick a region if asked), then save. The app checks the key for you.
  4. Pick a voice: tap ▶ to hear a sample first. Adjust the speed if you like.
  5. Check the estimate (length, characters), then tap Generate AI voice.
  6. Wait a few seconds to a few minutes depending on length. Then listen, practise dictation or shadowing, or download the file.

6. Câu hỏi thường gặp & lỗi6. FAQ & troubleshooting

App báo "API Key không hợp lệ"The app says "invalid API key"

Kiểm tra: (1) đã sao chép đủ cả key, không thừa dấu cách; (2) key chưa bị xóa trên trang nhà cung cấp; (3) với MiniMax và Alibaba, đã chọn đúng Region; (4) với iFlytek, không đảo APIKey và APISecret. Nếu vẫn lỗi, hãy tạo key mới và nhập lại.

Check that: (1) you copied the whole key with no extra spaces; (2) the key hasn't been deleted on the provider's site; (3) for MiniMax and Alibaba, the region is right; (4) for iFlytek, APIKey and APISecret aren't swapped. If it still fails, create a new key and add it again.

Báo hết tiền / hết hạn mứcIt says out of credit / quota

Tài khoản của bạn ở nhà cung cấp đã hết số dư hoặc hết lượng miễn phí. Hãy vào trang Billing của nhà cung cấp để nạp thêm.

Your account with the provider has run out of balance or free quota. Top up on the provider's Billing page.

Nghe thử giọng có bị tính tiền không?Does previewing a voice cost money?

Có, nhưng nghe thử chỉ đọc một câu rất ngắn nên chi phí rất nhỏ, gần như bằng 0.

Yes, but a preview reads only one very short sentence, so the cost is tiny, close to zero.

Nhà cung cấp hoặc giọng báo "đang tạm dừng"A provider or voice says "paused"

Đôi khi Wo xue Hanyu tạm dừng một nhà cung cấp, model hoặc giọng khi họ gặp sự cố. Bạn vẫn nghe được các bản đã tạo; hãy chọn giọng hoặc nhà cung cấp khác để tạo mới.

Wo xue Hanyu sometimes pauses a provider, model or voice while it has problems. Versions you already made still play; pick another voice or provider to make new ones.

Làm sao đổi hoặc xóa API Key?How do I change or remove my key?

Trong màn Giọng đọc AI, ở ô API Key bấm nút ⋮ → Đổi API Key hoặc Xóa API Key. Để vô hiệu hóa key hoàn toàn, hãy xóa nó trên trang của nhà cung cấp.

On the AI voice screen, in the API Key box tap ⋮ → Change API Key or Remove API Key. To disable the key completely, delete it on the provider's website.

Sửa bài đọc thì audio có tự cập nhật không?If I edit the reading, does the audio update?

Không. App sẽ báo văn bản đã thay đổi; bấm Tạo phiên bản mới để có audio khớp với nội dung mới. Bản cũ vẫn được giữ trong danh sách phiên bản.

No. The app tells you the text has changed; tap Generate new version to get audio that matches. The old version stays in the version list.
